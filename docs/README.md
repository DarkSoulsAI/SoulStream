# SoulStream Docs

This folder contains the static bilingual documentation website for SoulStream.

中文：这里是 SoulStream 的中英双语静态文档站，可直接由 GitHub Pages 发布。

## Local preview

Open `index.html` in a browser, or serve the folder with any static file server.

## GitHub Pages

The repository includes `.github/workflows/pages.yml`, which publishes this folder when changes land on `main`. In the GitHub repository, set **Settings → Pages → Source** to **GitHub Actions**.
